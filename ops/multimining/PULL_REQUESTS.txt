Submitting separate PRs
  Compare each topic with the base listed above to review only that topic.
  For a PR to upstream main, first merge the listed prerequisite topics or
  cherry-pick the topic commits onto a branch containing those prerequisites.
  Comparing a stacked branch directly with upstream main includes its prerequisites.
  No upstream PR is created automatically by this publication.

Publication hygiene
  All new commits use the GitHub author's noreply identity.
  Hostnames are examples, test addresses are synthetic encodings, and example
  ports are independent of any deployment. Node/wallet secrets, live payout
  addresses, local paths, private configurations and mining logs are excluded.
  Private test block identifiers are excluded from the validation summary.
  Original local commits are not ancestors of the published feature branches.
